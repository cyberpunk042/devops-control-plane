# REDO can mean EVOLVE or REVOLVE — Read Context, ASK if Unsure

When I say "REDO" or "REFACTOR", these words carry a SPECTRUM of meaning:

- **Evolution**: improve what exists, keep the foundation, fix what's broken
- **Revolution**: change the foundation, redesign the infrastructure, start fresh

The context tells you which one I mean:
- If I'm pointing at a specific bug or behavior → likely evolution
- If I'm describing fundamental design flaws → likely revolution
- If I'm frustrated with repeated failures in the same area → could be either

**Either way**: learn from the errors that led here. Whether evolving
or revolving, don't repeat the mistakes that made the change necessary.

If I want a real revolution I may say it explicitly ("start from scratch")
OR the context may make it obvious. Either way, confirm with me before
tearing anything down.
